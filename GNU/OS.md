**GNU** is an operating system which is 100% free software. It was launched in 1983 by [[Richard Stallman|richard-stallman]] and has been developed by many people working together for the sake of freedom of all software users to control their computing. Technically, GNU is generally like Unix. But unlike [[Unix Operating System|unix]], GNU gives its users freedom.

> [!info] The GNU Operating System and the Free Software Movement
> 
> Since 1983, developing the free Unix style operating system GNU, so that computer users can have the freedom to share and improve the software they use.
> 
> https://www.gnu.org/
It consists of a Kernel and Packages.
