It is one of the following types:
- array type
- class type that has
- no user-declared or inherited constructors
- no private or protected direct(since C++17) non-static data members
- no [virtual base classes](https://en.cppreference.com/w/cpp/language/derived_class#Virtual_base_classes)
- no [private](https://en.cppreference.com/w/cpp/language/derived_class#Private_inheritance) or [protected](https://en.cppreference.com/w/cpp/language/derived_class#Protected_inheritance) direct base classes
- no virtual member functions
