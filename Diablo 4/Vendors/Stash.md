It is a storage chest where you keep excess gems, equipment, and consumables across characters
- Available from the start of the game.
==**Storage Capacity**==
- Stash can have a maximum of 4 tabs.
- At the start you will only have one tab.
- You can buy more tabs with ==100,000== gold.
- Each tab has 50 slots.
- Each tab can be given a custom name and icon for organization
==**Sharing Rules**==
|Scenario|Shared|
|---|---|
|Between same season Softcore characters|==Yes==|
|Between same season Hardcore characters|==Yes==|
|Between Eternal Softcore characters|==Yes==|
|Between Eternal Hardcore characters|==Yes==|
|Between different season characters|==No==|
|Between Seasonal and Eternal characters|==No==|
|Between Softcore and Hardcore characters|==No==|
**Simple Rule to Remember**
- Stash is only shared if characters are on the **exact same realm** (same Season + same mode)
- Any difference in Season or Softcore/Hardcore = completely separate stash
