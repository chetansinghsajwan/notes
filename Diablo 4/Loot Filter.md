- Introduced in ==Season 13==.
- Controls which items are shown or hidden on your screen so you stop sifting through junk — lets you set rules from simple to very specific
- Applies only to gear — does NOT affect crafting materials, gems, currency, or tempering consumables
- Free for all players — no expansion required
==Where to Find It==
- Options → Gameplay → scroll down → click **Open Loot Filter**. Enable the shortcut checkbox above it to add a quick access button directly to your Game Menu
- You can also bind a hotkey under Options → Controls → **Toggle Loot Filter** — useful to quickly peek at hidden loot without disabling your filter
==3 Layer System==
|Layer|What It Does|
|---|---|
|Filter|The overall filter — only one active at a time|
|Rules|Up to 25 rules per filter — each does one thing; can be toggled on/off individually|
|Conditions|Up to 10 conditions per rule — defines exactly what to target|
==4 Visibility Options Per Rule==
|Visibility|Effect|
|---|---|
|Show|Override a Hide rule — default state|
|Hide Text Label|Hides item name but retains glow on ground|
|Hide All|Completely hides item — cannot be picked up unless filter is toggled off|
|Recolor|Changes item label color to stand out — great for highlighting key items|
==All 10 Available Conditions==
|**Condition**|Use Case|
|---|---|
|**Item Power Range**|Hide items below a minimum power threshold|
|**Item Rarity Match**|Filter by Common, Magic, Rare, Legendary, Unique etc.|
|**Item Properties**|Filter Ancestral vs non-Ancestral items|
|**Codex Upgrade Check**|Show only Legendaries that upgrade your Codex rank|
|**Greater Affix Check**|Filter items with 1 to 4 Greater Affixes|
|**Item Type Match**|Filter specific item types — weapon types, armor slots|
|**Has Required Affixes**|Must-have stats — e.g. only show items with Crit Chance|
|**Has Optional Affixes**|Preferred but not mandatory stats|
|**Is Specific Unique**|Target exact Unique or Mythic Unique drops|
==Critical Rule — Top to Bottom Priority==
- Rules apply top-down — a rule higher in the list overrides anything below it. If a Show rule sits below a Hide rule, the Hide catches everything first making the Show rule meaningless
==Import / Export==
- Select your filter → click the three-dot button → tap Export — copies a filter string to clipboard. To import, select New Filter → paste the Import Code
- Community filter libraries are already being shared on Reddit and Discord — grab pre-built filters from maxroll.gg
==Quick Setup for Endgame Rogue (Recommended)==
|Rule Order|Rule|Condition|
|---|---|---|
|1 (top)|Show — Ancestral + Greater Affix|Ancestral + 1+ Greater Affix|
|2|Show — Specific Uniques|Is Specific Unique (Azurewrath etc.)|
|3|Show — Codex Upgrades|Codex Upgrade Check|
|4|Hide All — Rare items|Item Rarity Match → Rare|
|5|Hide All — Magic items|Item Rarity Match → Magic|
|6|Hide All — Common items|Item Rarity Match → Common|
==Pro Tips==
- Only one filter can be active at a time — but you can toggle individual rules on/off without rebuilding — great for switching between farming goals
- Don't set up the filter at the start — at the beginning almost every item is useful; loot filter is most valuable in endgame
- Use **Recolor** on Greater Affix items — they stand out instantly in the loot explosion
- Check **maxroll.gg/d4/resources/loot-filter** for community recommended filter setups
