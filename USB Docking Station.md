# Ports
### Core upstream
- **USB-C (to laptop)** – data + video + power delivery
- **USB-A (older docks)** – data only
### Display
- **HDMI** – most common monitor output
    
	**Purpose**
    
	- Carries **video + audio** from dock to monitor/TV/projector.
	- Very common on displays.
    
	**Versions**
    
	- **HDMI 1.4** → up to **4K @ 30Hz** (OK for basic 4K desktop).
	- **HDMI 2.0** → **4K @ 60Hz** (ideal for smooth desktop/video).
	- **HDMI 2.1** → **4K @ 120Hz, 8K @ 60Hz** (rare on docks; mostly for gaming gear).
- **DisplayPort (DP)** – higher refresh / multi-monitor friendly
    
	**Purpose**
    
	- Transmits **video + audio** like HDMI, but with **higher bandwidth and flexibility**.
	- Common on laptops and monitors, especially for high-refresh and pro use.
    
	**Versions**
    
	- **DP 1.2** → up to **4K @ 60Hz**
	- **DP 1.4** → **8K @ 60Hz** or **4K @ 120Hz** (good for high-refresh gaming/creators)
	- **DP 2.0** → much higher bandwidth (rare in docks currently)
    
	Higher version = supports **higher resolution + refresh + color depth**.
    
- **VGA** – legacy monitors (older docks)
- **DVI** – rare, legacy
### USB expansion
- **USB-A 2.0 / 3.0 / 3.2** – keyboard, mouse, drives
    
	**Purpose**
    
	USB-A ports let you connect keyboards, mice, flash drives, printers, external storage, dongles, and similar peripherals.
    
	**Versions**
    
	- **USB-A 2.0** – up to **480 Mbps** (okay for keyboards/mice/printers, slow for big file transfers).
	- **USB-A 3.0 / 3.2 Gen1** – up to **5 Gbps** (good everyday speed).
	- **USB-A 3.2 Gen2** – up to **10 Gbps** (faster transfers for SSDs/large files).
    
	**Practical purchase points**
    
	- For **flash drives & external HDD/SSD**, prefer **USB-A 3.x** (5–10 Gbps).
	- **Older USB-A 2.0** ports are fine for keyboards/mice but too slow for storage devices.
	- Check if ports support **power (charging)** when laptop is asleep. Some docks offer charging on USB-A.
    
	**Compatibility notes**
    
	- All USB-A ports are backward compatible (A3.x → works with A2.0 devices, slower).
- **USB-C (downstream)** – data, sometimes charging
### Networking
- **Ethernet (RJ-45)** – wired internet (10/100/1000 Mbps or 2.5G)
    
	**What it is**
    
	Wired network port (RJ-45) that gives your laptop **Internet/LAN** through the dock.
    
	**Speed types you’ll see**
    
	- **Fast Ethernet** – **100 Mbps** (rare now; too slow for most uses).
	- **Gigabit Ethernet (1 Gbps)** – **standard** for office/home; smooth video calls & file transfers.
	- **2.5G / 5G / 10G Ethernet** – faster than 1 Gbps; nice if your router/NAS supports it (helps big LAN transfers).
    
	**Why it matters**
    
	- **Reliable connection:** Wired is steadier than Wi-Fi, great for video calls, big file sync, cloud backups.
	- **Lower latency:** Useful for gaming or real-time apps.
	- **No interference:** Wi-Fi can fluctuate; Ethernet stays consistent.
### Audio
- **3.5 mm combo jack** – headphone + mic
- **Separate mic / headphone jacks** – pro docks
    
	**What it does**
    
	Carries **headphone/speaker output** and **mic input** without needing a separate USB sound card.
    
	**Types you’ll encounter**
    
	- **Combo jack (single 3.5 mm)** — supports **headphones + mic** on one port (CTIA/AHJ standard).
	- **Separate jacks** — one for **headphones/speakers**, one for **mic** (older pro setups).
    
	**What it’s really good for**
    
	- Plugging in **wired headphones**, **earbuds**, **desktop speakers**, or **headsets**
	- Simple audio setup without extra USB dongles
	- Quick laptop audio when you’re docked
### Power
- **USB-C Power Delivery input** – laptop charging (60W–100W)
- **DC barrel jack** – external power adapter (older models)
### Storage / extras
- **SD card reader** – cameras
- **microSD card reader** – phones, drones
- **Kensington lock slot** – physical security
    
	**What it is**
    
	- A **small rectangular metal slot** on devices (docks, laptops, monitors).
	- Used to attach a **physical security cable**.
    
	**How it works**
    
	- A Kensington-style cable lock goes into the slot.
	- You twist/lock it → anchors the device to a desk or fixed object.
    
	**Why it exists**
    
	- **Theft deterrent**, not theft-proof.
	- Common in **offices, labs, libraries, shared workspaces**.
    
	**Types**
    
	- **Kensington (K-slot)** – most common.
	- **Nano lock** – smaller, used on thin devices.
	- **Wedge lock** – used by some OEMs (HP, Dell variants).
    
	**Buying considerations**
    
	- Useful only if your setup is in a **public or shared space**.
    
- **Thunderbolt 3 / 4** – high-end docks (fast data + multiple displays)
