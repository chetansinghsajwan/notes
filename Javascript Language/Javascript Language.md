JavaScript is a [[Prototype Based Language|prototype-based]], multi-paradigm, single-threaded, [[Dynamically Typed Language|dynamically-typed]] language, supporting [[Object Oriented Language|object-oriented]] styles.
### Javascript and Ecmascript
The core language of JavaScript is standardized by the ECMA TC39 committee as a language named ECMAScript.
**What parts of javascript fall under ecmascript?**
Among other things, ECMAScript defines:
- Language syntax
- Error handling mechanisms
- Data types
- A prototype-based inheritance mechanism
- Built-in objects and functions, including
- A module system
- Basic memory model
